## Issues Found

### 🔴 CRITICAL: Producer Signup Missing `producerProfile`

**Impact**: Medium
- Producers created without producerProfile structure
- May cause issues when checking `userProfile.producerProfile?.organizationId`
- Code expects this field to exist

**Fix Required**: Add stub producerProfile on signup
```typescript
const producerData = userType === 'club-owner' ? {
  betaStatus: 'pending' as const,
  betaRequestedAt: new Date(),
  producerProfile: {
    organizationId: '',  // Empty until org is created
    onboardingCompleted: false
  }
} : {}
```

### 🟡 MINOR: Vendor Signup Missing `betaStatus`

**Impact**: Low
- Schema shows betaStatus is not marked as optional
- Vendors don't use beta approval
- May cause TypeScript warnings

**Options**:
1. Add `betaStatus: 'approved'` to vendor signups (vendors auto-approved)
2. Update schema to mark betaStatus as optional
3. Leave as-is (vendors never check betaStatus anyway)

**Recommendation**: Option 1 - Set vendors to auto-approved for consistency
