ROUTE PROTECTION COMPONENTS
================================================================================

┌─────────────────────────────────────────────────────────────────────┐
│ RedirectIfAuthenticatedV2 (components/auth/ProtectedRouteV2.tsx)   │
├─────────────────────────────────────────────────────────────────────┤
│ Purpose: Keep authenticated users off auth pages (login, etc.)     │
│                                                                      │
│ Logic:                                                               │
│  if (loading) return null                                           │
│  if (isAuthenticated) {                                             │
│    if (role === 'producer' || 'venue_owner')                       │
│      → Navigate to /producer/pending                               │
│    else if (role === 'vendor')                                     │
│      → Navigate to /vendor/pending                                 │
│    else if (role === 'consumer' || 'guest')                        │
│      → Navigate to /pending                                        │
│    else if (role === 'admin')                                      │
│      → Navigate to /admin/dashboard                                │
│  } else {                                                            │
│    render children (the auth page)                                 │
│  }                                                                   │
└─────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────┐
│ AdminRoute (components/auth/AdminRoute.tsx)                         │
├─────────────────────────────────────────────────────────────────────┤
│ Purpose: Restrict routes to admin users only                        │
│                                                                      │
│ Logic:                                                               │
│  if (loading) return LoadingTransition("Verifying admin access...")│
│  if (!isAuthenticated) → Navigate to /auth                          │
│  if (!isAdmin) → Navigate to /                                      │
│  else render children (AdminDashboard)                              │
└─────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────┐
│ RoleBasedDashboardRedirect (App.tsx)                                │
├─────────────────────────────────────────────────────────────────────┤
│ Purpose: Route authenticated users to their appropriate holding     │
│ screen based on role                                                │
│                                                                      │
│ Redirect Map:                                                        │
│  'producer' || 'venue_owner' → /producer/pending                   │
│  'vendor'                     → /vendor/pending                     │
│  'consumer' || 'guest'        → /pending                            │
│  'admin'                      → /admin/dashboard                    │
│  unknown                      → /                                   │
└─────────────────────────────────────────────────────────────────────┘


LOGIN FLOW SEQUENCE DIAGRAM
================================================================================

User
  │
  ├─→ LoginPage (pages/LoginPage.tsx)
  │     │
  │     └─→ User enters email/password
  │         │
  │         └─→ Form validation
  │             │
  │             └─→ handleSubmit()
  │                 │
  │                 └─→ signIn({ email, password })
  │                     │
  │                     └─→ AuthContext.handleSignIn()
  │                         │
  │                         ├─→ authApi.login(email, password)
  │                         │   │
  │                         │   └─→ POST /login
  │                         │       Backend returns: { token, id, ... }
  │                         │       │
  │                         │       └─→ saveAuthToken(token)
  │                         │           (localStorage: railsAuthToken)
  │                         │
  │                         ├─→ authApi.getCurrentUser()
  │                         │   │
  │                         │   └─→ GET /me (with Bearer token)
  │                         │       Backend returns: User object
  │                         │
  │                         ├─→ setCurrentUser(user)
  │                         ├─→ setUserProfile(user)
  │                         └─→ cacheUserProfile('rails-user', user)
  │                             (localStorage: user_profile_rails-user)
  │
  └─→ RedirectIfAuthenticatedV2 checks role
      │
      └─→ Navigate to role-based dashboard:
          ├─ /producer/pending (if producer)
          ├─ /vendor/pending (if vendor)
          ├─ /pending (if consumer/guest)
          └─ /admin/dashboard (if admin)


LOGOUT FLOW SEQUENCE DIAGRAM
================================================================================

User (in Dashboard)
  │
  └─→ Clicks "Sign Out"
      │
      └─→ handleSignOut()
          │
          ├─→ removeCachedUserProfile('rails-user')
          │   (Removes from localStorage)
          │
          ├─→ authApi.logout()
          │   │
          │   └─→ DELETE /logout (with Bearer token)
          │       Backend invalidates session
          │
          ├─→ clearAuthToken()
          │   (Removes railsAuthToken from localStorage)
          │
          ├─→ setCurrentUser(null)
          ├─→ setUserProfile(null)
          └─→ setLoading(false)
              │
              └─→ navigate('/')
                  (Redirect to home page)

CACHING STRATEGY
================================================================================

Cache Type: localStorage (client-side)

User Profile Cache
├─ Key: user_profile_rails-user
├─ Value: User object (JSON string)
├─ TTL: 5 minutes
└─ Usage:
    ├─ Loaded on app mount for instant UX
    ├─ Fresh profile fetched in background
    ├─ Cleared on logout
    └─ Cleared on token expiration

Token Storage
├─ Key: railsAuthToken
├─ Value: JWT token string
├─ Persistence: Persistent (no TTL)
└─ Usage:
    ├─ Added to Authorization headers
    ├─ Checked on app mount
    └─ Cleared on logout

ERROR HANDLING
================================================================================

API Errors
├─ ApiError class (services/api.ts)
│  ├─ message: string (user-friendly)
│  ├─ status: number (HTTP status)
│  └─ errors?: string[] (detailed errors)
│
├─ Error Scenarios:
│  ├─ Invalid credentials → "Invalid email or password"
│  ├─ Email exists → "Email has already been taken"
│  ├─ Network error → Connection/timeout message
│  ├─ Expired token → Token cleared, user logged out
│  └─ API errors → Caught and re-thrown
│
└─ Error Display:
   ├─ LoginPage: Alert component at form top
   ├─ AuthContext: Stored in error state
   └─ Components: Call clearError() to dismiss
