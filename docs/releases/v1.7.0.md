# Release v1.7.0 - RSVP & Subscription System
**Release Date**: September 19, 2025
**Status**: ✅ Production Deployed

## 🎯 **Release Overview**
Complete RSVP and subscription management system with enhanced user experience, glass morphism UI design, and robust backend integration.

## 🚀 **Major Features**

### **RSVP Management System**
- **Event Registration**: Full RSVP flow with "Going" and "Maybe" options
- **Calendar Integration**:
  - Download .ics files for calendar apps
  - Direct Google Calendar and Outlook integration
  - Event details automatically populated
- **Admin Dashboard**: Real-time RSVP tracking and management
- **Email Notifications**: Automated confirmations and updates

### **Subscription Management**
- **Club Subscriptions**: Users can subscribe to organization updates
- **Admin Controls**: Subscription management and analytics
- **Email Integration**: Automated subscriber notifications
- **Rate Limiting**: Prevents spam and abuse

### **Enhanced UI/UX**
- **Glass Morphism Design**: Modern frosted glass aesthetic

- **Improved Accessibility**: Better screen reader support

## 📝 **API Changes**

### **New Endpoints**
```
POST /api/registrations - Create RSVP or subscription
GET /api/registrations/event/:eventId - Get event registrations
PATCH /api/registrations/:id/email-sent - Mark email as sent
GET /api/registrations/debug - Debug endpoint for validation testing
```

### **Updated Types**
- `registrationType`: Now supports `'rsvp_yes' | 'rsvp_maybe' | 'subscription'`
- Enhanced validation for email addresses and registration data
- Improved error response structure
